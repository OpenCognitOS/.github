## One harness for every agent

<p align="center">
  <img src="https://raw.githubusercontent.com/OpenCognitOS/opencognit-releases/main/assets/screens/harness.jpg" width="900" alt="Harness: what flows into every agent, graded A to D" />
</p>

Every coding CLI brings its own instructions, tools and approvals. OpenCognit puts **one harness** on top:
the same `AGENTS.md`, the same MCP servers and the same guardrails for every agent — and a **grade from A to D**
that tells you when something is off: an `AGENTS.md` that's too large, references to files that no longer exist,
a tool missing in one CLI, outdated decisions in the project memory. One click hands the cleanup to an agent.

- **Local.** No cloud, no account, no telemetry — it uses the CLIs you already have.
- **Safe by default.** Every shell command is checked against your guardrails; signed updates only.
- **When a limit hits,** another agent takes over the work.
- **Free:** 4 agents and 2 projects, every feature. **Full version:** €69 once, 12 months of updates, no subscription.
